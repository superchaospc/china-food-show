# The China Food Show

Use this workflow when a user wants a finished English edition of a food video. If the user supplies only a link in a project that uses this workflow by default, inspect the title or sample first. Respect requests to download, analyze, or revise only one element separately.

1. **Prepare the source.** Run `scripts/episode.py URL` to locate the workspace. Obtain the authorized video through the user's downloader, or reuse an existing source. Bind the local file with `scripts/episode.py URL --source FILE`. Record geometry, display rotation, timestamps and audio streams. Use the same workspace when resuming. For links with multiple parts, process the requested part.
2. **Prepare a clean picture.** If an authorized source needs watermark repair, prefer dedicated software such as HitPaw Edimakor's Watermark Remover. Read the actual quote against the user's current approval before submitting. Assign one operator per paid job and recover the existing result after interruptions. Preserve the existing captions. Check moving textures before adding a new logo. See [Finishing](references/finish.md).
3. **Map the original captions.** Record the source words and their first and last visible frames. Use each measured Chinese interval for its English cue, including every cut and blank frame. Create paired intervals when both languages need new captions. Place English above the original Chinese. See [Captions](references/captions.md).
4. **Cast the speakers you hear.** Use the creator's authorized voice for the host when one is configured. Pick a distinct, consistent voice for each other meaningful speaker. Leave speech-free scenes without narration. Use the words of the final English performance for both burned-in dialogue captions and the English SRT. Group replies inside the corresponding Chinese display interval. Update both after any shortening, substitution or new take. Every price, including a repeated quote, must carry its USD equivalent immediately after the source amount on the same English subtitle line in the MP4 and SRT. Keep the pair together when wrapping. Remove any separate corner price overlay. Check planned text, voice identities, and billing authorization before paid generation. Use a clean ambience stem and optionally mix a user-supplied music bed. See [Audio](references/audio.md).
5. **Render and check the decoded export.** Use the validated, full-length clean picture, ASS captions and aligned final audio mix. Supply a transparent PNG and the measured original watermark rectangle only when appropriate. Preserve native frame timing; check all subtitle changes, blank intervals, repaired moving edges, speech assignment and audio peaks. Compare the caption words in order with the final recorded turns, including short replies. Check every rendered cue and SRT boundary against the independently measured Chinese frames. Require zero frames of difference at appearances, switches, disappearances and gaps. Correct timing and price-placement failures before delivery. Keep the matching English SRT in the episode workspace for verification and revisions. Record any remaining defects or unverified stages.

## Vertical edition and posters

Follow [Vertical video delivery](references/vertical.md) for the complete 1080 × 1920 episode and a separate 2:59 edit when the source exceeds 3:00. Use the creator's approved series artwork for the panels. Select one real frame that shows the episode's distinctive selling point. Use that same photograph for both posters, with a separate crop for 3:4 and 9:16. See [Poster selection and design](references/covers.md).

## Final delivery

Under the user's chosen publishing directory, keep one folder per episode. Place the full vertical MP4, any 2:59 cut, `Poster-3x4.jpg`, `Poster-9x16.jpg` and `Title and Description.txt` together. Label video versions in the filenames and update each edition in place.

Use the approved English YouTube title and posting description, preserving its paragraph breaks. If copy has yet to be written, draft it from the facts of this episode. Put the English title on the first line, leave one blank line, then add the description. Use exactly three hashtags in the entire file. Place them on the final line exactly as follows: `#chinesefood #streetfood #cooking`. Deliver only this combined copy file. Keep the SRT, previews and production materials in the workspace. When revising an older delivery, move any previously delivered SRT back to the workspace. Deliver the episode once the final video and its companion files have passed their checks. For a revision, update the affected files in the same delivery folder. Verify the contents against the approved versions, reveal the folder in Finder on macOS, and return its path.
